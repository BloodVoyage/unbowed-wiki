# Unbowed Suite

Welcome to the official documentation for the **Unbowed** dialogue overhaul suite.

---

## 📋 Core Requirements
* **Skyrim Special Edition** (v1.5.97 / v1.6+)
* **SKSE64**
* **SkyUI**
* **Unbowed MCM Core Utility** *(Available on Nexus Mods)*

## 🛠️ Installation Guide
1. Download and install the **Unbowed MCM Core Utility** from Nexus Mods using your mod manager (MO2 / Vortex).
2. Download the desired archetype `.7z` package from the catalog link above.
3. Install the `.7z` package as a normal mod in your mod manager and enable it.
