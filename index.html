Unbowed I: Dunmer Dialogue Overhaul

Expands NPC interactions, lore-friendly dialogue trees, and unique voice line distributions for Dunmer characters throughout Skyrim and Solstheim.

⚠️ Compatibility Note: Put Unbowed_Dunmer.esp after any general dialogue overhaul mods in your load order to avoid dialogue topic overrides.

🛠️ Installation Guide

  1. Download and install the Unbowed MCM Core Utility using your preferred mod manager (Mod Organizer 2 / Vortex).
  2. Download the desired archetype package (.7z) from the catalog link.
  3. Install the .7z archive as a mod in MO2/Vortex and activate it.
  4. Run SKSE64 and verify settings via the MCM menu in-game.
