Unbowed I: Dunmer Dialogue Overhaul

Expands NPC interactions, lore-friendly dialogue trees, and unique voice line distributions for Dunmer characters throughout Skyrim and Solstheim.

📋 Core Requirements

  • Skyrim Special Edition (v1.5.97 / v1.6+ AE compatible)
  • SKSE64 (Matching your runtime version)
  • SkyUI
  • Unbowed MCM Core Utility (Required for in-game configuration)

🛠️ Installation Guide

🚫 Mod Manager Requirement: Unbowed is NOT compatible with Vortex or any Nexus-derived mod management software. You must use Mod Organizer 2 (MO2) to install and deploy this mod family.
  1. Download and install the Unbowed MCM Core Utility via Mod Organizer 2.
  2. Download the desired archetype package (.7z) from the catalog table above.
  3. Install the .7z archive into MO2 and activate it in your mod list.
  4. Run Skyrim via SKSE64 and verify your configuration in the MCM menu in-game.
⚠️ Load Order Note: Place Unbowed_Dunmer.esp after any general dialogue overhaul mods in your load order to avoid topic overrides.
